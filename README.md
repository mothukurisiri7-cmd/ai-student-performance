# AI Student Performance Prediction System

An AI-based student performance prediction application that analyzes attendance, study hours, and subject marks to predict overall performance.

## Features

- Student performance prediction
- Attendance analysis
- Daily study-hour analysis
- Mathematics, Science, and English analysis
- Performance level classification
- Risk-level prediction
- Strongest and weakest subject detection
- Personalized weekly study plan

## Technology

- Python
- Streamlit

## How to Run

```bash
streamlit run app.py
